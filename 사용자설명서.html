EV 보조금 신청 자동화 사용자설명서

배포 폴더 안의 EVAutomation.exe를 실행해서 ev.or.kr 판매자 신청서를 자동 작성하고, PDF 3종을 첨부한 뒤 지원신청까지 진행하는 프로그램입니다.

이 파일은 인터넷 연결 없이도 열 수 있습니다. 다른 PC로 옮길 때는 EVAutomation 폴더 전체를 복사하세요.

1. 폴더 구성

배포 폴더는 아래 구조로 사용합니다.

EVAutomation\
  EVAutomation.exe
  env\
    양태건.env
    노태윤.env
    안윤준.env
  files\
    양태건보조금구매지원신청서.PDF
    양태건차량구매계약서.PDF
    양태건주민등록등본.PDF
  • env 폴더: 신청자별 설정 파일을 넣습니다.
  • files 폴더: 신청자별 첨부 PDF를 넣습니다.
  • EVAutomation.exe: 실행 파일입니다.

2. PDF 파일명 규칙

PDF 파일명은 env 파일 안의 NAME 값과 정확히 같아야 합니다.

env 값 필요한 PDF 파일명
NAME=양태건 양태건보조금구매지원신청서.PDF
양태건차량구매계약서.PDF
양태건주민등록등본.PDF
파일명 앞부분의 이름, 띄어쓰기, 오타가 다르면 자동 첨부가 실패합니다. 확장자는 .PDF 또는 .pdf 모두 보통 문제 없지만, 가능하면 예시처럼 맞춰두세요.

3. env 파일 준비

env 폴더에서 신청자별 .env 파일을 열어 내용을 확인합니다.

항목 설명
SEARCH지자체 검색어입니다. 예: 청주
NAME신청자 이름입니다. PDF 파일명 앞부분과 일치해야 합니다.
CAR_MODEL신청 차종입니다. 사이트의 차종 명칭과 정확히 일치해야 합니다.
CONTRACT_DAY계약일입니다. 형식: YYYY-MM-DD
DELIVERY_DATE출고예정일입니다. 형식: YYYY-MM-DD
ADDRESS, ADDRESS2주소와 상세주소입니다.
SMART_UPLOAD_DIR=filesPDF를 files 폴더에서 찾도록 하는 설정입니다.

4. 실행 순서

  1. EVAutomation.exe를 실행합니다.
  2. 프로그램 화면에서 사용할 칸의 Chrome 버튼을 누릅니다.
  3. 열린 Chrome에서 ev.or.kr에 로그인합니다.
  4. 프로그램 화면에서 env 옆의 ... 버튼을 눌러 신청자 env 파일을 선택합니다.
  5. files 폴더에 해당 신청자의 PDF 3개가 있는지 확인합니다.
  6. 실행 버튼을 누릅니다.
  7. 자동 입력, 스마트 파일 첨부, 적용, 지원신청이 순서대로 진행됩니다.
현재 방식에서는 FILE1 첨부 파일 선택 칸을 직접 고르지 않아도 됩니다. 프로그램이 files 폴더에서 NAME 기준으로 PDF 3개를 자동으로 찾습니다.

5. 실행 전 체크리스트

  • Chrome 로그인 완료
  • env 파일의 NAME과 PDF 파일명 앞부분 일치
  • files 폴더에 PDF 3개 존재
  • PDF 1개당 10MB 이하
  • 스마트 업로드 파일 수 7개 이하
  • 차종명, 계약일, 출고예정일, 연락처, 주소 확인

6. 자주 나는 오류

PDF 파일을 찾지 못한다고 나올 때

  • files 폴더 안에 PDF가 있는지 확인합니다.
  • env의 NAME 값과 파일명 앞부분이 같은지 확인합니다.
  • 예: NAME=양태건이면 파일명도 반드시 양태건...으로 시작해야 합니다.

신청서 화면에서 멈출 때

  • ev.or.kr 로그인 세션이 풀렸는지 확인합니다.
  • Chrome이 프로그램에서 연 포트의 창인지 확인합니다.
  • 로그에 저장된 화면 캡처/HTML 파일이 있으면 개발자에게 전달합니다.

차종 선택 오류가 날 때

  • env의 CAR_MODEL 값이 사이트 차종명과 정확히 같은지 확인합니다.
  • 띄어쓰기, 괄호, 슬래시 앞뒤 문구가 다르면 선택이 실패할 수 있습니다.

7. 다른 PC로 옮길 때

  1. dist 안의 EVAutomation 폴더를 통째로 복사합니다.
  2. 다른 PC에 붙여넣습니다.
  3. env 폴더와 files 폴더가 같이 있는지 확인합니다.
  4. EVAutomation.exe를 실행합니다.
